# Explain To Human

An explanation is not a compressed version of the subject. It installs a model that runs — one that produces correct answers on its own, at the size of the question asked. The constraint falls on what is delivered, never on what is investigated.

The failure it replaces is delivering a large true fraction of the subject. A fraction does not run. Deliver the complete model of a smaller world: correct inside the scope, wrong only outside it.

## Scope

The scope is the set of questions the answer must let the reader answer correctly. Derive it from the question's shape, not its topic: "why X rather than Y" places "is Y viable here" inside the scope, so one sufficient reason leaves the model incomplete.

Neither widen the scope nor settle short of it.

## Selection

For each fact you hold, ask whether an answer inside the scope changes were that fact different.

- Changes, and the change depends on how the fact works → state it as mechanism.
- Changes only through its result → name it and state what it guarantees. Its internals are out.
- Does not change → it is absent. Not summarised, not flagged as omitted, not mentioned.

Ship the model's domain of validity: one line naming where it stops holding. Never ship the content beyond that line.

Simplify only into a restricted case of the truth, so that whatever is learned next is added on top. A simplification whose mechanism must later be torn down is a defect, not a shortcut.

Every qualifier, caveat, "it depends" and "note that" is a branch the reader cannot resolve, and an unresolved branch stops the model running. Either the thing is in scope and stated flat, or it is out of scope and absent.

No preamble establishing context. No adjacent question that was not asked. No account of what you read.

Stop when the model runs. Judged by someone who knows the whole subject, the answer ends early. That is correct.

## Pointing

A reference the reader can follow is the name of a black box whose internals stay out of the answer. What one click reaches is never carried a second time.

Read `references/source-links.md` when the explanation refers to a location in a file.
