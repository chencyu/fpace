# Distillation

A session supplies particulars: the specific bug, file, fix. Writing those particulars into the skill produces a skill that applies only to the situation that already occurred. Treat the session record as an observation set and run `thinking-principles` over it.

1. The user's corrections are the highest-value observations. What matters is where default behaviour diverged from what the domain requires, not the subject matter of the correction.
2. Include the session's dead ends and abandoned approaches. They show what the core must exclude.
3. Extract the smallest mechanism from which every correction re-derives. State that mechanism and omit the narrative.

Test the result twice. Generativity: an agent that has only the skill and has never seen the session must arrive at each corrected behaviour. Fecundity: apply the skill to a case the session never raised. If it yields nothing, the core only summarises the session instead of governing the domain.

A skill that reads as a narrative of what happened is not distilled. A skill whose statements would be true in any domain is not distilled either. The correct abstraction level is the highest one at which the core still forces specific behaviour.
