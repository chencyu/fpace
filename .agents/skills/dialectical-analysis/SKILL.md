# Dialectical Analysis

Use only for claims with a contestable thesis, not determinate technical questions.

1. Resolve the proposition into its load-bearing claims and grounds; verify its core from intrinsic constraints rather than convention or analogy.
2. Reconstruct the strongest version before generating its antithesis; otherwise the opposition is a straw man.
3. Stress-test independently:
	- **Information:** data accuracy; source validity, currency, and applicability.
	- **Logic:** structure, fallacies, hidden assumptions, and invalid inferences.
	Name which track fails: either can fail while the other holds.
4. Test against the strongest opposing view. If logic and data survive, acknowledge that instead of forcing disagreement; truth, not contrarianism, is the goal.
